# Code of Conduct

## Our Commitment

DeceptionX is an open-source security research and engineering project. We want the project to be a respectful, constructive, and welcoming environment for everyone who contributes.

We are committed to providing a harassment-free experience regardless of background, experience level, or role in the project.

---

## Expected Behavior

Contributors are expected to:

* Be respectful and professional.
* Communicate constructively, especially during technical disagreements.
* Give useful and actionable feedback.
* Respect different levels of experience and knowledge.
* Focus discussions on the project and its technical goals.
* Take responsibility for mistakes and work toward resolving them.
* Protect sensitive information shared during project work.

---

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, discrimination, or personal attacks.
* Threats or intimidation.
* Trolling or deliberately disruptive behavior.
* Sexual or inappropriate comments or content.
* Publishing someone's private information without permission.
* Sharing credentials, secrets, private keys, or sensitive security data.
* Deliberately introducing malicious code or unsafe changes.
* Using the project to facilitate unauthorized access or attacks.

Security research discussions are welcome, but all testing must be performed on systems and environments you are authorized to use.

---

## Security and Responsible Disclosure

If you discover a security vulnerability in DeceptionX, please avoid publicly posting sensitive technical details before the issue can be reviewed.

When reporting a vulnerability, provide enough information to reproduce and understand the issue while avoiding:

* Credentials or authentication tokens
* Private keys
* Personal information
* Real victim data
* Publicly exploitable attack details when unnecessary

If the repository provides a dedicated security reporting process, please use that process instead of opening a public issue.

---

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Depending on the situation, actions may include:

* A warning
* Removal of inappropriate content
* Temporary restriction from project discussions
* Removal from the project or community

The response will consider the severity and circumstances of the behavior.

---

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers through the project's available private communication or security-reporting channels.

When reporting an incident, include:

* What happened
* When it happened
* Where it happened
* Relevant messages or evidence
* Any immediate security concerns

Please avoid publicly sharing sensitive information.

---

## Scope

This Code of Conduct applies to project spaces, including:

* GitHub issues
* Pull requests
* Discussions
* Project-related communication
* Other spaces where someone is representing DeceptionX
